## 📝 Descrição do Projeto

Este projeto é uma aplicação web de CRUD (Create, Read, Update, Delete) para administração de usuários. Foi desenvolvido como projeto prático para a disciplina de **Desenvolvimento Web I** do curso de Desenvolvimento de Software Multiplataforma da **Fatec Luigi Papaiz**.

O objetivo foi aplicar e consolidar os conhecimentos adquiridos nas tecnologias fundamentais da web para criar uma solução funcional de gerenciamento de dados no lado do cliente.

**Professor Responsável:** Prof. PhD. Bruno Zolotareff dos Santos.

## ✨ Funcionalidades

-   **Criar (Create):** Adicionar novos usuários ao sistema.
-   **Ler (Read):** Buscar e visualizar usuários cadastrados.
-   **Atualizar (Update):** Editar as informações de usuários existentes.
-   **Deletar (Delete):** Remover usuários do sistema.
-   **Persistência de Dados:** As informações são salvas e recuperadas diretamente no `localStorage` do navegador, permitindo que os dados persistam entre as sessões.

## 🛠️ Tecnologias Utilizadas

-   **HTML5:** Estruturação semântica do conteúdo.
-   **CSS3:** Estilização visual, layout e design responsivo.
-   **JavaScript (ES6+):** Interatividade, manipulação do DOM e implementação de toda a lógica do CRUD.
